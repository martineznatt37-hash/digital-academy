# Escape del Hacker — App Android

Proyecto Capacitor listo para generar una app de **Google Play Store**.

## Comandos útiles

```powershell
cd C:\Users\marti\OneDrive\Desktop\digital-academy\escape-app

# Copiar el juego + sincronizar con Android
npm run sync

# Abrir Android Studio
npm run open
```

## Publicar en Play Store

Lee la guía completa: **[PLAY-STORE.md](./PLAY-STORE.md)**

Resumen:
1. Instala Android Studio
2. Crea cuenta en Google Play Console (~25 USD)
3. Genera un **Android App Bundle (.aab)** firmado
4. Súbelo en Play Console
